ورود به Firefox VPN

پنل گذرواژه را فقط از راه HTTPS یا تونل SSH می‌گیرد و برای ورود مستقیم به API رسمی Firefox Accounts استفاده می‌کند؛ گذرواژه در فایل یا log ذخیره نمی‌شود. اگر Firefox کد ایمیل، TOTP یا لینک تأیید بخواهد، همان مرحله در پنل نمایش داده می‌شود. پاسخ HTTP 406 به معنی چالش امنیتی است؛ این نسخه آن را دور نمی‌زند.

تغییر گذرواژهٔ ورود به پنل

طول رمز انتخابی توست: ۱ تا ۲۵۶ نویسه. رمز کوتاه در پنل عمومی امنیت کمتری دارد. پس از تغییر، مرورگر برای احراز هویت دوباره رمز جدید را می‌خواهد.

لوکیشن‌ها و پورت‌های پراکسی

ورودی‌ها SOCKS5 و بدون نام‌کاربری/گذرواژه هستند. اگر پورت را در اینترنت باز کنی، هرکسی می‌تواند از آن به‌عنوان پراکسی استفاده کند؛ برای جلوگیری از سوءاستفاده، در فایروال VPS و پنل ابری فقط IPهای خودت را مجاز کن. دسترسی نهایی هر لوکیشن را Mozilla بررسی می‌کند.
