# FoxyforVPS

داشبورد self-hosted اوبونتو برای مدیریت خروجی‌های SOCKS5 لوکیشن‌های Firefox VPN، پورت‌ها، quota و سرویس‌های پنل. Firefox Accounts دسترسی این پروژه را تضمین یا پشتیبانی رسمی نمی‌کند.

## ورود مستقیم Firefox از پنل

در نسخهٔ فعلی، فرم پنل ایمیل و رمز Firefox را می‌گیرد و آن‌ها را برای یک تلاش ورود به backend روی VPS می‌فرستد. Backend یک Chromium موقت را با کاربر لینوکسی جداگانهٔ `foxyvpsbrowser` اجرا می‌کند، صفحهٔ رسمی Firefox Accounts را باز می‌کند و WebChannel را مشابه پل WebView پروژهٔ FoxyVPN پردازش می‌کند. پس از گرفتن نشست، backend آن را با OAuth مبادله و درخواست نابودکردن session token را به Firefox می‌فرستد. Chromium و context آن بعد از تلاش بسته می‌شوند.

**رمز Firefox از VPS عبور می‌کند.** آن را فقط وقتی وارد کن که پنل را با HTTPS عمومی باز کرده‌ای (`https://domain:8777`) یا از تونل SSH محلی استفاده می‌کنی. هرگز فرم را روی HTTP عمومی باز نکن. برنامه رمز را در فایل، دیتابیس، command line، environment یا log نگه نمی‌دارد؛ فقط تا پایان درخواست در حافظه/pipe استفاده می‌شود. بااین‌حال، مدیر root VPS از نظر فنی قادر به مشاهدهٔ داده‌های برنامه است؛ فقط روی VPS خودت استفاده کن.

این ورود خودکار ممکن است با تغییر صفحهٔ Firefox Accounts، CAPTCHA، تأیید دومرحله‌ای، کد ایمیل یا محدودیت ضدربات متوقف شود. در این حالت برنامه challenge را دور نمی‌زند؛ خطا می‌دهد و رمز را ذخیره نمی‌کند. اگر Mozilla HTTP 406 یا خطای امنیتی بدهد، ورود در آن شبکه قابل تکمیل نیست. پس از تلاش ناموفق، پیام خطا را بررسی کن؛ رمز یا session token را در issue یا گفتگو نفرست.

## نصب و به‌روزرسانی Ubuntu

پس از قرار دادن فایل‌ها در شاخهٔ `main` مخزن `arefhere51/FoxyforVPS`:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/FoxyforVPS/main/manager.sh | sudo bash -s -- install
```

نصب، وابستگی‌های Python، Chromium، core سفارشی sing-box و سرویس‌های systemd را آماده می‌کند. بارگیری اولیهٔ Chromium و dependencyهای سیستم ممکن است چند دقیقه و چندصد مگابایت فضای دیسک مصرف کند. Firefox sign-in browser با کاربر محدود اجرا می‌شود؛ خود backend پنل همچنان root است تا بتواند فایل‌های core و systemd را مدیریت کند.

پس از نصب، رمز اولیهٔ پنل یک‌بار در ترمینال نمایش داده می‌شود. آن را در password manager ذخیره کن و از فرم **تغییر رمز ورود به پنل** رمزی با طول دلخواه ۱ تا ۲۵۶ نویسه انتخاب کن. رمزهای کوتاه، به‌ویژه برای پنل عمومی، ریسک بالاتری دارند. رمز جدید با PBKDF2 salted hash در فایل root-only ذخیره می‌شود؛ رمز تصادفی اولیه نیز root-only است.

```bash
sudo foxyforvpsctl menu
sudo foxyforvpsctl update
sudo foxyforvpsctl status
sudo foxyforvpsctl remove
```

بعد از تغییر رمز پنل، مرورگر را دوباره احراز هویت کن. اگر پنجرهٔ ورود خودکار ظاهر نشد، تب را ببند و آدرس پنل را دوباره باز کن.

## پنل خصوصی از طریق SSH

backend فقط روی `127.0.0.1:8778` VPS گوش می‌دهد. روی رایانهٔ خودت این تونل را باز و باز نگه‌دار:

```bash
ssh -L 8777:127.0.0.1:8778 USER@VPS
```

سپس `http://127.0.0.1:8777` را باز کن. در این حالت ترافیک از اتصال SSH محافظت می‌شود و فرم ورود Firefox می‌تواند به backend محلی تونل‌شده ارسال شود.

## پنل عمومی HTTPS روی پورت 8777

برای دسترسی عمومی به دامنه/زیردامنه نیاز است که DNS A/AAAA آن به **IP عمومی همین VPS** اشاره کند. Caddy روی پورت 8777 TLS/HTTPS را terminate می‌کند؛ backend روی loopback:8778 خصوصی می‌ماند. HTTP خام روی اینترنت عمداً پشتیبانی نمی‌شود.

پس از ثبت DNS اجرا کن:

```bash
sudo foxyforvpsctl public enable vpn.example.com
```

پنل در `https://vpn.example.com:8777` باز می‌شود. برای صدور و تمدید گواهی، TCPهای 80، 443 و 8777 را در firewall ارائه‌دهنده و UFW مجاز کن. اگر Caddy/Nginx/Apache یا سرویسی دیگر روی پورت‌های موردنیاز فعال باشد، برنامه از بازنویسی آن خودداری می‌کند.

برای خاموش‌کردن دسترسی عمومی:

```bash
sudo foxyforvpsctl public disable
```

## پراکسی‌ها

هر ورودی فقط SOCKS5 است و بدون نام‌کاربری/گذرواژه کار می‌کند. چون سرویس روی رابط عمومی VPS گوش می‌دهد، هر پورت قابل‌دسترسی از اینترنت به پراکسی باز تبدیل می‌شود. فایروال VPS و firewall ارائه‌دهنده را طوری تنظیم کن که پورت‌های فعال فقط از IPهای مورداعتماد خودت قابل‌دسترسی باشند؛ بازگذاشتن آن‌ها برای همهٔ اینترنت می‌تواند به سوءاستفاده، هزینهٔ ترافیک یا مسدودشدن VPS منجر شود. فایروال خودکار تغییر نمی‌کند. مصرف چند لوکیشن از quota مشترک همان حساب است. دسترسی نهایی هر لوکیشن را Mozilla تعیین می‌کند.

## رمزها و داده‌ها

- رمز Firefox فقط در جریان login از طریق HTTPS/SSH به VPS می‌رسد؛ کد آن را در storage دائمی نمی‌نویسد و بعد از نتیجهٔ درخواست، referenceهای آن را کنار می‌گذارد.
- صفحهٔ Firefox در Chromium موقت با کاربر محدود اجرا می‌شود. Screenshot، trace و log صفحه ذخیره نمی‌شود.
- session token در pipe/حافظه جابه‌جا می‌شود؛ در صورت موفقیت با OAuth مبادله و درخواست حذف آن به FxA ارسال می‌شود. اعتبارهای OAuth برای کارکرد سرویس با مجوز محدود در `/var/lib/foxyforvps/` باقی می‌مانند.
- رمز پنل پس از تغییر با PBKDF2 salted hash در `/etc/foxyforvps/admin-password` ذخیره می‌شود؛ فایل فقط root قابل خواندن است.
- پنل public فقط روی HTTPS و TCP 8777 در دسترس است؛ backend روی VPS loopback:8778 قرار دارد.
- quota از پاسخ API دریافت می‌شود؛ اگر در پاسخ نباشد، داشبورد «نامشخص» نشان می‌دهد.

## مجوز و سازگاری

FoxyforVPS یک پروژهٔ غیررسمی است و ممکن است با تغییرهای Mozilla Accounts/FxA یا firewall شبکه از کار بیفتد. کد protocol بر اساس FoxyVPN و fork متن‌باز sing-box تنظیم شده است. قبل از فعال‌کردن تعداد زیادی خروجی، یک لوکیشن را آزمایش کن.
