# FoxyforVPS

داشبورد خودمیزبان اوبونتو برای خواندن فهرست عمومی سرورهای Firefox VPN، مدیریت یک listener SOCKS5 احراز هویت‌شده برای هر کشور، تنظیم پورت، روشن/خاموش‌کردن لوکیشن‌ها و نمایش سهمیه‌ای که Mozilla از API در اختیار می‌گذارد.

## وضعیت مهم پیش از نصب

این پروژه از APIها و هستهٔ سفارشی متن‌باز FoxyVPN استفاده می‌کند؛ **Mozilla این داشبورد یا اتصال چندلوکیشنی روی VPS را رسماً پشتیبانی نمی‌کند**. سرویس ممکن است بر اساس کشور، حساب، سهمیه، تغییر endpoint یا پاسخ ضدبات HTTP 406 از کار بیفتد. سرورهای قرنطینه‌شده از فهرست حذف می‌شوند. علامت `locked` در Remote Settings فقط اخطار است؛ اجازهٔ نهایی را Mozilla برای همان حساب بررسی می‌کند و این ابزار محدودیت حساب را دور نمی‌زند. هیچ سقف عمومی و مستندی برای تونل‌های همزمان پیدا نشده است، پس پذیرش همزمان همهٔ خروجی‌ها تضمین‌شده نیست.

**ایمیل و رمز حساب Firefox در این برنامه وارد یا ذخیره نمی‌شوند.** FoxyVPN از پیام WebChannel در مرورگر/WebView برای دریافت session token موقت و سپس OAuth/PKCE استفاده می‌کند. این بسته یک افزونهٔ متن‌باز Firefox دارد که فقط پیام ورود از `accounts.firefox.com` را در حافظهٔ همان تب می‌گیرد؛ هیچ چیزی ارسال نمی‌کند تا کاربر خودش روی دکمهٔ افزونه بزند. توکن با کد جفت‌سازی تصادفی، یک‌بارمصرف و ۱۰ دقیقه‌ای از طریق پورت loopback و تونل SSH به VPS منتقل و بلافاصله با OAuth مبادله می‌شود. رمز حساب از افزونه هم خوانده نمی‌شود.

این افزونه یک پل محلیِ آزمایشی است، نه افزونهٔ رسمی Firefox/Mozilla. رویداد WebChannel در WebView FoxyVPN دیده شده است، اما این جریان در هر نسخه/تنظیم مرورگر Firefox تضمین‌شده نیست. اگر رویداد به افزونه نرسد یا Mozilla پاسخ HTTP 406 بدهد، ورود کامل نمی‌شود. در چنین حالتی برنامه باید متوقف بماند؛ رمز حساب را در پنل وارد نکن و محدودیت سرویس را دور نزن.

## نصب با یک خط روی Ubuntu

پس از اینکه این پوشه را در شاخهٔ `main` مخزن عمومی `arefhere51/FoxyforVPS` قرار دادی:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/FoxyforVPS/main/manager.sh | sudo bash -s -- install
```

این اسکریپت Python/FastAPI را نصب می‌کند و هستهٔ sing-box فورک‌شدهٔ Foxy را از تگ ثابت `v1.15.0-foxy-masque.2` می‌سازد. کامپایل هسته ممکن است چند دقیقه زمان و حافظهٔ قابل‌توجه بخواهد؛ Ubuntu، systemd، اینترنت و Go 1.21+ (با دریافت toolchain لازم توسط Go) نیاز است.

در پایان، رمز مدیر پنل فقط یک‌بار روی ترمینال چاپ می‌شود. آن را نگه‌دار. منوی مدیریت:

```bash
sudo foxyforvpsctl menu
```

گزینه‌های `install`، `update`، `remove`، وضعیت سرویس و لاگ وجود دارد. حذف کامل، داده‌های حساب/توکن و تنظیمات برنامه را هم پاک می‌کند.

## اتصال به پنل و ورود Firefox

پنل فقط روی `127.0.0.1:8777` گوش می‌دهد. روی رایانهٔ خودت این تونل SSH را باز کن و آن را باز نگه‌دار:

```bash
ssh -L 8777:127.0.0.1:8777 USER@VPS
```

سپس برو به `http://127.0.0.1:8777` و رمز مدیر را در Basic Auth مرورگر وارد کن. **پورت 8777 را به اینترنت عمومی باز نکن.**

برای ورود، در پنل «ساخت کد ورود مرورگری» را بزن. در Firefox دسکتاپ، به `about:debugging#/runtime/this-firefox` برو و «Load Temporary Add-on» را انتخاب کن. فایل `browser-helper/manifest.json` را از ZIP انتخاب کن. همان Firefox را روی صفحهٔ رسمی `accounts.firefox.com` وارد حساب کن. پس از login، روی آیکن افزونه کلیک کن، کد یک‌بارمصرف پنل را در آن وارد و ارسال را انتخاب کن. افزونه فقط در پاسخ به کلیک، توکن نشست را روی تونل SSH به VPS می‌فرستد. بعد از موفقیت، پنل به‌طور خودکار آن را با OAuth مبادله می‌کند و خود session token را ذخیره نمی‌کند. افزونهٔ موقت ممکن است پس از بستن Firefox نیاز به بارگذاری دوباره داشته باشد.

## پراکسی‌ها

هر پراکسی SOCKS5 روی رابط عمومی VPS و با نام‌کاربری/گذرواژهٔ جداگانه ساخته می‌شود. به‌صورت پیش‌فرض، پورت‌ها از 2020 به بعد تخصیص می‌گیرند. فایروال خودکار تغییر داده نمی‌شود. اگر می‌خواهی از دستگاهی به پراکسی وصل شوی، در فایروال VPS فقط پورت‌های لازم را برای IPهای مورداعتماد باز کن؛ از بازکردن عمومی پورت‌های بدون محدودیت خودداری کن.

## دستورها

```bash
sudo foxyforvpsctl install
sudo foxyforvpsctl update
sudo foxyforvpsctl status
sudo foxyforvpsctl remove
```

برای بازسازی اجباری هسته بعد از تغییر نسخه/پچ:

```bash
sudo FORCE_BUILD_CORE=1 foxyforvpsctl update
```

## امنیت و داده‌ها

- رمز مدیر در `/etc/foxyforvps/admin-password` و اعتبارهای FxA/Guardian در `/var/lib/foxyforvps/` با دسترسی root-only ذخیره می‌شوند.
- رمز حساب Firefox در این پروژه درخواست یا ذخیره نمی‌شود.
- اعتبار SOCKS هر خروجی در فایل تنظیمات root-only ذخیره می‌شود. برای استفاده، از آن‌ها مثل رمز حساس محافظت کن.
- پورت داشبورد فقط loopback است؛ خروجی‌های SOCKS به‌خاطر استفاده از کلاینت بیرونی روی همهٔ رابط‌ها bind می‌شوند و باید با گذرواژه و firewall محدود شوند.
- هر لوکیشن از سهمیهٔ همان حساب استفاده می‌کند. مصرف چند خروجی می‌تواند سهمیه را سریع‌تر تمام کند.
- دادهٔ سهمیه از endpointهای Mozilla خوانده می‌شود؛ اگر پاسخ سهمیه در دسترس نباشد، پنل «نامشخص» نشان می‌دهد و عدد ساختگی تولید نمی‌کند.

## توسعهٔ محلی

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
FOXY_ADMIN_PASSWORD='set-a-long-local-test-password' uvicorn foxyforvps.app:app --host 127.0.0.1 --port 8777
```

توسعهٔ محلی به‌تنهایی هستهٔ MASQUE را نصب نمی‌کند. فایل‌های هسته فقط روی Ubuntu/systemd نصب VPS معنا دارند.

## ارجاع و مجوز

جریان API و مدل تنظیم sing-box بر اساس رفتار قابل‌مشاهدهٔ پروژهٔ [Vauth/FoxyVPN](https://github.com/Vauth/FoxyVPN) با مجوز MIT بررسی شده است. کد هستهٔ sing-box از fork و تگ مشخص‌شده دریافت می‌شود؛ مجوز آن در مخزن upstream اعمال می‌شود. این مخزن وابسته یا مورد تأیید Mozilla نیست و نام Firefox/Mozilla فقط برای شناسایی سرویس استفاده شده است.
