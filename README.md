# FoxyforVPS

داشبورد خودمیزبان اوبونتو برای خواندن فهرست عمومی سرورهای Firefox VPN، مدیریت خروجی SOCKS5 برای لوکیشن‌ها، تنظیم پورت و نمایش سهمیه‌ای که Mozilla از API در اختیار می‌گذارد.

## وضعیت و محدودیت‌ها

این پروژه از APIها و هستهٔ سفارشی متن‌باز FoxyVPN استفاده می‌کند؛ **Mozilla این داشبورد یا اتصال چندلوکیشنی روی VPS را رسماً پشتیبانی نمی‌کند**. دسترسی به لوکیشن‌ها و quota به حساب و سیاست/تغییرهای سرویس وابسته است. پذیرش همزمان همهٔ خروجی‌ها تضمین‌شده نیست.

رمز حساب Firefox از پنل یا افزونه خواسته یا ذخیره نمی‌شود. برای ورود باید در سایت رسمی Firefox Accounts وارد شوی؛ افزونهٔ Firefox فقط رویداد WebChannel رسمی را دریافت می‌کند. آن رویداد را content script ایزولهٔ عادی نمی‌تواند قابل‌اتکا بخواند، بنابراین نسخهٔ جدید listener جداگانه‌ای در `MAIN` world دارد. توکن فقط پس از کلیک کاربر، با کد یک‌بارمصرف و از HTTPS یا تونل SSH به VPS فرستاده می‌شود؛ افزونه آن را فقط در `storage.session` حافظه‌ای نگه می‌دارد و backend آن را با OAuth مبادله می‌کند.

## نصب در Ubuntu

پس از قرار دادن فایل‌ها در شاخهٔ `main` مخزن `arefhere51/FoxyforVPS`:

```bash
curl -fsSL https://raw.githubusercontent.com/arefhere51/FoxyforVPS/main/manager.sh | sudo bash -s -- install
```

این اسکریپت Python/FastAPI را نصب می‌کند و هستهٔ sing-box فورک‌شدهٔ Foxy را از تگ ثابت می‌سازد. کامپایل ممکن است چند دقیقه زمان و حافظهٔ قابل‌توجه بخواهد. در پایان نام‌کاربری `admin` و رمز تصادفی پنل فقط یک بار روی ترمینال نمایش داده می‌شود؛ آن را نگه‌دار.

مدیریت سرویس:

```bash
sudo foxyforvpsctl menu
sudo foxyforvpsctl update
sudo foxyforvpsctl status
sudo foxyforvpsctl remove
```

## پنل خصوصی از طریق SSH

backend فقط روی `127.0.0.1:8778` VPS گوش می‌دهد. روی رایانهٔ خودت این تونل را باز و باز نگه‌دار:

```bash
ssh -L 8777:127.0.0.1:8778 USER@VPS
```

سپس `http://127.0.0.1:8777` را باز کن و Basic Auth را با کاربر `admin` و رمز نصب وارد کن. پورت backend روی رابط عمومی VPS bind نمی‌شود.

## پنل عمومی امن روی TCP 8777

برای بازشدن پنل از اینترنت، به یک **دامنه/زیردامنه که DNS A/AAAA آن به IP همین VPS اشاره کند** نیاز است. پورت عمومی 8777 به‌صورت HTTPS/TLS با Caddy سرو می‌شود؛ Uvicorn/FastAPI همچنان روی loopback خصوصی 8778 می‌ماند. HTTP خام روی 8777 عمداً پشتیبانی نمی‌شود.

پس از ثبت DNS، اجرا کن:

```bash
sudo foxyforvpsctl public enable vpn.example.com
```

آدرس پنل می‌شود `https://vpn.example.com:8777`. صدور/تمدید گواهی Caddy خودکار است. در firewall ارائه‌دهنده و UFW، TCP 80، 443 و 8777 را برای challenge/HTTPS مجاز کن؛ فقط TCP 8777 محل دسترسی کاربر به پنل است. اگر یکی از پورت‌ها توسط سرویس دیگری گرفته شده یا Caddy از قبل فعال است، فرمان عمداً پیکربندی آن سرویس را بازنویسی نمی‌کند و متوقف می‌شود. برای بستن دسترسی عمومی:

```bash
sudo foxyforvpsctl public disable
```

اگر دامنه نداری، از تونل SSH استفاده کن. پنل Basic Auth دارد؛ رمز آن را خصوصی نگه‌دار.

## ورود Firefox و جفت‌سازی افزونه

1. در پنل، «ساخت کد ورود مرورگری» را بزن. کد ۱۰ دقیقه اعتبار و فقط یک‌بار مصرف دارد.
2. در Firefox دسکتاپ 128 یا جدیدتر، `about:debugging#/runtime/this-firefox` را باز کن، **Load Temporary Add-on** را بزن و `browser-helper/manifest.json` را از پوشهٔ استخراج‌شده انتخاب کن.
3. popup افزونه را باز و «بازکردن صفحهٔ رسمی ورود Firefox» را بزن. این لینک flow لازم برای WebChannel (`service=sync`, `context=fx_desktop_v3`) را باز می‌کند.
4. در همان تب به Firefox Accounts وارد شو؛ پس از redirect به settings، باز هم همان تب را نگه‌دار.
5. افزونه را باز کن. آدرس پنل را وارد کن: `http://127.0.0.1:8777` اگر تونل SSH برقرار است، یا `https://vpn.example.com:8777` برای پنل عمومی. در حالت عمومی Firefox فقط برای همان hostname مجوز اختیاری می‌خواهد.
6. کد پنل را وارد و ارسال را بزن. اگر پیامی دریافت نشد، لینک ورود افزونه را دوباره استفاده کن و ورود را در همان تب تازه انجام بده.

توکن در افزونه به دیسک ذخیره نمی‌شود و پس از تحویل حذف می‌شود. اگر افزونه موقت با بستن Firefox حذف شد، دوباره بارگذاری‌اش کن. این پل آزمایشی و غیررسمی است؛ اگر Mozilla شبکه را رد کرد (مثلاً HTTP 406)، رمز را در پنل وارد نکن.

## پراکسی‌ها

هر پراکسی SOCKS5 روی رابط عمومی VPS و با نام‌کاربری/گذرواژهٔ جداگانه ساخته می‌شود. فایروال خودکار تغییر نمی‌کند. فقط پورت‌های لازم را برای IPهای مورداعتماد باز کن؛ بازکردن عمومی SOCKS می‌تواند دسترسی ناخواسته ایجاد کند. مصرف چند لوکیشن از quota مشترک همان حساب است.

## امنیت و داده‌ها

- رمز پنل در `/etc/foxyforvps/admin-password` و اعتبارهای FxA/Guardian در `/var/lib/foxyforvps/` با دسترسی محدود ذخیره می‌شوند.
- رمز Firefox در این پروژه درخواست یا ذخیره نمی‌شود.
- توکن مرورگر در افزونه فقط در حافظهٔ نشست و در VPS فقط هنگام درخواست exchange استفاده می‌شود؛ اعتبارهای OAuth پایدار با مجوز root-only ذخیره می‌شوند.
- پورت backend پنل روی loopback:8778 است. در حالت عمومی، Caddy TLS روی دامنه و TCP 8777 terminate می‌کند.
- Mozilla quota را از API برمی‌گرداند؛ اگر در دسترس نباشد پنل «نامشخص» نشان می‌دهد، نه عدد ساختگی.

## ارجاع و مجوز

منطق protocol/config براساس FoxyVPN با مجوز MIT و fork مشخص‌شدهٔ sing-box بررسی شده است. این پروژه وابسته یا مورد تأیید Mozilla نیست. علت و مستندات تغییر افزونه در [`docs/DEBUGGING.md`](docs/DEBUGGING.md) آمده‌اند.
